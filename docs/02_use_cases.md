# **Use Case Diagram (Диаграмма прецедентов)**

**Основные действующие лица (Актеры):**   
1.Администратор стойки регистрации (Receptionist): Основной пользователь.    
2.Горничная (Housekeeper): Обновляет статусы уборки.  
3.Менеджер (Manager): Просматривает отчеты, управляет тарифами.  
4.Система онлайн-бронирования (внешняя): Передает данные о брони.  

**Описание прецедентов (Use Cases):**
* Receptionist:  
  - Забронировать номер (по телефону/при личном визите).  
  - Заселить гостя (Check-in).  
  - Выселить гостя (Check-out) и принять оплату.  
  - Продлить проживание.  
  - Отменить бронь.  
* Housekeeper:  
  - Просмотреть список задач (какие номера убрать).  
  - Отметить номер как "Убран".  
  - Сообщить о поломке (создать заявку в тех. службу).  
* Manager:  
  - Просмотреть отчет о загрузке.  
  - Изменить стоимость номера.  
  - Управлять пользователями системы.
