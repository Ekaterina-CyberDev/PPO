# Диаграмма состояний (State Machine Diagram)

**Цель:** Показать жизненный цикл ключевой бизнес-сущности «Номер» и правила перехода между состояниями.

### Правила и условия:
*   В состоянии «Занят» номер находится, пока в нем проживает гость.
*   После выезда гость уходит, но номер нельзя заселять, пока его не уберут (состояние «Грязный»).
*   В ремонт номер можно отправить из любого состояния, но только при наличии подтвержденной заявки от техслужбы (Guard condition).
